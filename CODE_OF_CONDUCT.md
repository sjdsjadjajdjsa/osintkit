# Code of conduct

Adapted from the Contributor Covenant, version 2.1.

## Our pledge

We make participation in this project harassment-free for everyone, regardless of experience,
identity, or background.

## Expected behaviour

- Be direct and kind. Critique the change, not the person.
- Assume good faith; ask before rewriting someone else's work.
- Accept that "no, and here is why" is a complete answer.
- Credit prior art and other people's findings.

## Unacceptable behaviour

- Harassment, insults, or dismissive gatekeeping.
- Publishing others' private data without consent (fits this project especially).
- Sustained off-topic noise in issues or pull requests.
- Plagiarism or uncredited vendoring.

## Scope

Issues, pull requests, discussions, and anywhere the project is represented.

## Enforcement

Report by opening an issue or tagging the maintainer in the thread. Consequences scale with the
offence: a nudge, a comment cleanup, or removal from the project. Decisions are explained, and
appeals are heard once.

Maintainers may edit or delete contributions that break these rules.
